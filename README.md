# 11月分進捗
## 操作説明
移動：矢印キー  
攻撃：スペースキー

### 実装した仕様
- D03.滑る床  
  - その床に乗ると滑るようにした  
### その他
1. 滑る床から普通の床に乗ったり、普通の床から滑る床に乗る時に違和感が残ってしまった
1. 慣性が普通の床に乗っていても残ってしまうことがある
1. 10月では、梯子を上るためにWSでやらなくてはいけなかったが、スムーズに矢印で登れるようになった   
1. 滑る床に手間取って、次に作ろうと思っていた崩れる床が11月中に出来なかった
